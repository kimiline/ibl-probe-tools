Urchin + Slice Trajectory Viewer

How to install, launch, and use the probe trajectory viewer GUI for NP2.4 insertions registered in Alyx, and the lab's Lasagna for checking the histology.

Setup
!

Prerequisites

You need the IBL iblenv conda environment. If you don't have it, follow the IBL ephys installation guide first.

You also need oursin 0.7.2 installed in iblenv:

conda activate iblenv
pip install oursin==0.7.2
After installing oursin, you must patch one line in its source file. Open:
…\anaconda3\envs\iblenv\Lib\site-packages\oursin\renderer.py
Find line 40 and change the URL to:
client.sio.connect('https://pinpoint.allenneuraldynamics-test.org:5000')
1

Download the tools

Clone the repository to a folder of your choice:

git clone https://github.com/kimiline/ibl-probe-tools.git

This creates an ibl-probe-tools folder containing the GUI scripts and their .bat launchers.

2

Edit the launcher file

Open trajectory_viewer_urchin.bat in Notepad. Replace the username kimil with your own Windows username on the Python path line:

C:\Users\YOUR_USERNAME\anaconda3\envs\iblenv\python.exe "%~dp0trajectory_viewer_urchin.py"

If Anaconda is installed system-wide rather than per-user, the path may start with C:\ProgramData\anaconda3\ instead.

3

Launch the GUI

Double-click trajectory_viewer_urchin.bat. A login dialog will appear asking for your Alyx credentials. If you have previously logged in on this machine, it will connect automatically and skip the dialog.

Alyx URL https://alyx.internationalbrainlab.org (pre-filled) Username Your IBL Alyx username Password Your IBL Alyx password
Using the GUI
4

Load probe sessions

  1. In the Subject dropdown, select the mouse you want to view.
  2. In the Session dropdown, select a recording session. Sessions are listed in date-ascending order.
  3. Click Add Session to load that session's probe trajectories, or click Load All to load every session for that subject at once.
  4. Repeat for additional subjects or sessions. Each loaded session appears in the probe tree below the controls.

To remove everything and start over, click Clear All.

 

Slice panel navigation

Three slice panels are shown: coronal (AP slice), sagittal (ML slice), and horizontal (DV slice). Probe trajectories appear on each panel as faint lines, with a bright dot at the slice intersection.

Move slice position Scroll the mouse wheel over a panel (50 µm per tick). Or type a value directly in the AP / ML / DV spinboxes in the sidebar.
Place crosshair Left drag on any panel to move the crosshair and navigate all three slices to that location simultaneously.
Pan a panel Ctrl + Left drag to pan the view without changing the slice position.
Orientation All panels use the lab's "surgeon's view": looking down on the brain from behind the animal. Horizontal: anterior at the top, the animal's right on screen-right. Coronal: dorsal up, right on right. Sagittal: dorsal up, anterior on the right. Urchin and Lasagna open in the same orientation.
 

Probe tree: visibility and colors

The tree lists every loaded session, probe, and shank. Each entry has a color swatch on the right.

Show / hide Check or uncheck any item in the tree. Checking a session or probe row toggles all its shanks at once. Use Check All / Uncheck All to toggle everything.
Recolor a session Double-click the color swatch on a session or probe row to open a color picker. All shanks in that group update together.
5

Open the 3D Urchin view

The Urchin 3D view is optional. Load probe sessions first, then:

  1. In the Atlas dropdown (top bar), confirm CCF 25 µm is selected (the default).
  2. Click 1. Open Urchin. A browser tab opens automatically at the Urchin renderer and the 3D brain loads. This takes a few seconds.
  3. Once the status bar shows Urchin ready, loaded probe trajectories appear in the 3D view automatically.
  4. Use the Brain alpha slider (top bar) to adjust the transparency of the grey brain surface.
  5. Urchin opens looking down on the top of the brain, anterior at the top, the animal's right on screen-right. If you rotate the brain by dragging, click Reset view to return to this orientation.
The brain is nearly symmetric, so after rotating it is easy to misread which hemisphere a probe is in. Use Reset view, or check the axes cross at the top of the Urchin window: its blue arm points toward the animal's left.
The atlas selector is locked once Urchin is open. Choose the atlas before clicking Open Urchin.
6

Highlight brain regions

After Urchin is open, use the Brain Regions section at the bottom of the sidebar to highlight CCF brain areas in the 3D view. Regions appear with their canonical Allen Brain Atlas colors as solid opaque meshes.

  1. Type one or more CCF acronyms in the text box, separated by commas, for example: VISam, FN, CA1
  2. Press Enter or click Add. The regions appear in the 3D view immediately.
  3. To remove a single region, right-click its name in the list and choose Remove region.
  4. To remove all highlighted regions at once, click Clear All Regions.
Acronyms are case-sensitive and must match the Allen CCF exactly (e.g. VISam not visam). If an acronym isn't recognised, the status bar will say Not found in atlas.
Histology in Lasagna
7

Install and update Lasagna

The lab uses a modified Lasagna that opens registered histology in the same orientation as the trajectory viewer. Install it once, in its own conda environment (not iblenv):

conda create -n lasagna python=3.11
conda activate lasagna
pip install git+https://github.com/kimiline/lasagna.git

To launch it:

conda activate lasagna
lasagna

To update to the latest version:

conda activate lasagna
pip install --upgrade --force-reinstall --no-deps git+https://github.com/kimiline/lasagna.git
8

Open histology stacks

  1. Press Ctrl + Shift + O (or File > Load ingredient > Open multiple stacks) and select both channel files, e.g. STD_ds_KM_077_GR.tif and STD_ds_KM_077_RD.tif.
  2. A dialog lists each file with a color. Colors are picked from the file name (GR green, RD red); change any that are wrong, then click OK.
  3. The stacks open in surgeon's view, and the status bar confirms it. The file dialog remembers the last folder you used.

To open a single stack instead, press Ctrl + O.

 

Lasagna navigation and orientation

Zoom Scroll the mouse wheel over a panel.
Step through slices Ctrl + scroll. Add Shift to move 5 slices at a time.
Pan Left drag. The other panels pan with it.
Jump to a point Ctrl + Left drag in one panel moves the other two panels to that location.
Reset zoom Ctrl + R
Flip a view On the Axis tab, use Flip A-P, Flip L-R or Flip D-V. Flips change only the display, never the data, so traced points stay correct.
Quit Ctrl + Q
Registered TIFFs (STD_ds_*, brainreg output) are stored posterior-first, and Lasagna corrects for this automatically, the same way IBL's alignment GUI does. If a stack ever opens with the olfactory bulbs at the bottom of the horizontal view, click Flip A-P.
